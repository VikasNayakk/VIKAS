# Cloud Computing

## Overview
Cloud computing delivers servers, storage, and services over the internet.

## Service Models
- IaaS: Virtual machines and networking.
- PaaS: Managed platforms for apps.
- SaaS: Ready-to-use software online.

## Popular Providers
- AWS, Azure, Google Cloud.

## Key Concepts
- Scalability: Add or remove resources as needed.
- Availability: Redundancy and uptime.
- Regions and zones.
- Pay-as-you-go pricing.

## Common Services
- Compute (VMs, containers).
- Storage (object, block, file).
- Databases (managed SQL/NoSQL).
- CDN for fast content delivery.

## Pros and Cons
- Pros: Flexibility, cost control, global access.
- Cons: Ongoing costs, vendor lock-in, security responsibility.
