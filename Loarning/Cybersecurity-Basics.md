# Cybersecurity Basics

## Overview
Cybersecurity protects systems, networks, and data from attacks. Basic security habits prevent most common issues.

## Common Threats
- Malware: Viruses, ransomware, spyware.
- Phishing: Fake emails or websites stealing data.
- Password attacks: Brute force, credential stuffing.
- Social engineering: Tricking users to reveal info.

## Core Principles
- Confidentiality, Integrity, Availability (CIA triad).
- Least privilege access.
- Defense in depth.

## Essential Practices
- Use strong unique passwords.
- Enable two-factor authentication.
- Keep OS and apps updated.
- Avoid unknown links and attachments.
- Back up important data.

## Tools
- Antivirus/anti-malware.
- Firewall.
- Password managers.
- VPN for public Wi-Fi.

## Incident Basics
- Disconnect affected device from network.
- Run scans and remove threats.
- Change passwords after cleanup.
