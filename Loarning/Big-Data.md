# Big Data

## 1) What is Big Data?
Big Data means data that is too large, too fast, or too complex for traditional databases to handle efficiently.

## 2) The 5 Vs
- Volume: huge size (TB, PB, EB)
- Velocity: fast data generation (streams, real-time)
- Variety: many formats (text, images, video, logs)
- Veracity: data quality and trust
- Value: useful insights and business impact

## 3) Big Data Architecture (Simple Flow)
1. Data Sources ->
2. Ingestion (batch/stream) ->
3. Storage (data lake/warehouse) ->
4. Processing (batch/stream) ->
5. Analytics/ML ->
6. Visualization/Action

## 4) Storage Options
- Data Lake: raw data in files (HDFS, S3, Azure Data Lake)
- Data Warehouse: structured data for analytics (Snowflake, BigQuery)
- NoSQL DBs: flexible schema (MongoDB, Cassandra)

## 5) Processing Types
- Batch processing: large data in chunks (Hadoop, Spark)
- Stream processing: live data (Kafka, Spark Streaming, Flink)

## 6) Common Tools
- Hadoop (HDFS, MapReduce)
- Apache Spark
- Kafka
- Hive, Presto, Trino
- Airflow for pipelines
- Delta Lake / Iceberg

## 7) Use Cases
- Fraud detection
- Recommendation systems
- Predictive maintenance
- Real-time analytics
- Log monitoring
- Personalization

## 8) Challenges
- Cost and scalability
- Data quality and governance
- Security and privacy
- Complexity of pipelines
- Skilled talent requirement

## 9) Skills to Learn
- SQL and data modeling
- Python (pandas, pyspark basics)
- Linux and cloud basics
- Data pipelines and ETL
- Visualization and dashboards

## 10) Mini Project Idea
Build a simple analytics pipeline:
- Collect sample logs or CSV data
- Store in a data lake folder
- Process with Python or Spark
- Generate a summary report and chart

## 11) Quick Revision
Big Data = large + fast + diverse data. Use distributed storage and processing to analyze and create value.
