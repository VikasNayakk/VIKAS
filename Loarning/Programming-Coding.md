# Programming / Coding

## Overview
Programming is writing instructions to solve problems and build software. Understanding basics helps you learn any language faster.

## Core Concepts
- Variables and Data Types: int, float, string, bool.
- Control Flow: if/else, loops (for/while).
- Functions: Reusable blocks of code.
- Data Structures: arrays, lists, dictionaries, sets.
- OOP: Classes, objects, inheritance, encapsulation.

## Popular Languages
- Python: Easy to learn, automation, data science.
- JavaScript: Web development.
- Java: Enterprise apps and Android.
- C/C++: Systems and performance-critical apps.
- C#: Windows apps and game dev (Unity).

## Development Tools
- IDEs: VS Code, PyCharm, IntelliJ.
- Version Control: Git and GitHub.
- Debuggers: Step-through execution to find bugs.

## Learning Roadmap
1) Learn basic syntax and data types.
2) Practice small programs and logic problems.
3) Learn OOP and file handling.
4) Build real projects (web app, automation, CLI).
5) Learn testing and debugging skills.

## Best Practices
- Write clean, readable code.
- Use meaningful variable names.
- Keep functions small and focused.
- Comment only when logic is complex.

## Common Errors
- Syntax errors: Missing brackets, wrong indentation.
- Runtime errors: Divide by zero, null references.
- Logic errors: Program runs but output is wrong.

## Build vs Run
- Compiled languages: C/C++ (build then run).
- Interpreted languages: Python, JS (run directly).
