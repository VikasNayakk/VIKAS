# System Troubleshooting

## Overview
Troubleshooting means identifying, isolating, and fixing system problems logically. Start simple, change one thing at a time.

## Common Symptoms and Causes
- Slow PC: Low RAM, storage full, malware, too many startup apps.
- No boot: PSU issues, RAM not seated, drive failure.
- Blue Screen: Driver problems, hardware faults, corrupted system files.
- No internet: Router issues, DNS problems, ISP outage.

## Troubleshooting Steps
1) Observe the exact error or symptom.
2) Check recent changes (updates, installs).
3) Verify power, cables, and connections.
4) Restart and re-test.
5) Isolate hardware/software.
6) Search logs or error codes.
7) Apply the fix and test again.

## Windows Tools
- Task Manager: Monitor CPU, RAM, Disk usage.
- Event Viewer: View system logs.
- Device Manager: Driver issues and hardware status.
- Disk Cleanup: Remove temporary files.

## Basic Commands
- sfc /scannow: Repair system files.
- chkdsk: Check disk errors.
- DISM: Repair Windows image.

## Malware Checks
- Run full antivirus scan.
- Remove suspicious startup apps.
- Check browser extensions.

## Backup and Recovery
- Regular backups reduce data loss.
- Use restore points before big updates.

## When to Seek Help
- Hardware damage or burning smell.
- Frequent BSODs with hardware errors.
- Data recovery needed from failed drive.
