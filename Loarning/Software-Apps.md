# Software / Apps

## Overview
Software includes system software (OS, drivers) and applications (browsers, editors, games). Understanding software layers helps with performance tuning, troubleshooting, and security.

## Types of Software
### 1) System Software
- Operating Systems: Windows, macOS, Linux.
- Device Drivers: Software that connects hardware with the OS.
- Utilities: Disk management, backup tools, antivirus.

### 2) Application Software
- Productivity: Office suites, note apps, PDF tools.
- Creativity: Photoshop, video editors, music tools.
- Communication: Zoom, Teams, email clients.
- Development: IDEs, compilers, terminals.

## Software Installation
- Sources: Official websites, app stores, package managers.
- Install modes: Typical, custom, portable.
- Best practice: Avoid bundled junk and unknown sources.

## Software Updates
- Why: Fix bugs, improve performance, patch security holes.
- Types: Security updates, feature updates, driver updates.
- Tip: Keep OS and drivers up to date, but avoid unstable beta versions on production systems.

## Common File Types
- Executables: .exe, .msi, .app, .deb, .rpm
- Documents: .docx, .pdf, .txt
- Media: .mp4, .mp3, .png, .jpg
- Archives: .zip, .rar, .7z

## Performance Optimization
- Disable unnecessary startup apps.
- Remove unused software.
- Keep enough free disk space (15%+ recommended).
- Use lightweight alternatives if system is low-end.

## Security Basics
- Install reputable antivirus.
- Keep firewall enabled.
- Avoid pirated software (high risk of malware).
- Use strong passwords and two-factor authentication.

## Licensing Models
- Freeware: Free to use.
- Shareware: Trial-based, paid for full features.
- Open-source: Source code available.
- Subscription: Monthly/yearly payments.

## Troubleshooting Software
- App crashes: Update, reinstall, check logs.
- Slow performance: Clear cache, update drivers.
- Compatibility issues: Run in compatibility mode or use older versions.
