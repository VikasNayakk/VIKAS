# Networking Advanced

## Overview
Advanced networking covers deeper topics like routing, segmentation, and diagnostics.

## Routing and Switching
- Routing: Directs traffic between networks.
- Switching: Connects devices within a network.
- VLANs: Segment networks for security and performance.

## Protocols
- TCP vs UDP: Reliability vs speed.
- HTTP/HTTPS: Web traffic.
- SSH: Secure remote access.

## Security Concepts
- NAT: Hides internal IPs.
- Firewall rules: Allow/deny traffic.
- IDS/IPS: Detect or prevent attacks.

## Diagnostics
- traceroute/tracert: Path analysis.
- netstat: Active connections.
- nslookup: DNS checks.

## Performance
- Bandwidth vs latency.
- QoS: Prioritize important traffic.
