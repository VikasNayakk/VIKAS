# Performance Optimization

## Overview
Performance optimization improves speed, responsiveness, and resource usage on systems.

## System Level
- Disable unnecessary startup apps.
- Clean temporary files.
- Keep drivers updated.
- Use SSD for faster boot and load times.

## Application Level
- Update apps to latest stable versions.
- Reduce background processes.
- Clear caches when apps become slow.

## Storage Tips
- Keep at least 15% free disk space.
- Defragment HDDs (not SSDs).
- Monitor disk health with SMART tools.

## Network Tips
- Use wired connections when possible.
- Place router in open space.
- Update router firmware.

## When to Upgrade
- Add RAM if usage is always high.
- Upgrade to SSD if still on HDD.
- Replace weak PSU or overheating cooling.
