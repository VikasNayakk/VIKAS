# System Administration

## Overview
System administration focuses on maintaining and configuring computers and servers for reliable operation.

## Core Tasks
- User and permission management.
- Installing and patching software.
- Monitoring system health.
- Managing storage and backups.

## Monitoring Basics
- CPU, RAM, disk, and network usage.
- Log monitoring for errors.
- Uptime checks.

## Automation
- Use scripts to repeat tasks.
- Schedule tasks and backups.

## Security Tasks
- Apply updates regularly.
- Enforce password policies.
- Audit access and logs.

## Documentation
- Keep notes on changes.
- Maintain inventory of hardware and software.
