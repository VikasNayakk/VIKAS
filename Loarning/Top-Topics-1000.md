1. Artificial Intelligence
	- Focuses on making machines act intelligently in real-world tasks.
	- Combines logic, search, learning, perception, and decision-making.
	- Uses data, rules, or both to solve problems.
	- Powers assistants, recommendations, fraud checks, and robotics.
	- Includes symbolic AI and statistical AI approaches.
	- Requires good data, clear goals, and measurable outcomes.
	- Raises ethics concerns like bias and transparency.
	- Needs evaluation metrics to compare models fairly.
	- Benefits from strong compute and scalable infrastructure.
	- Often integrated into products as features, not standalone tools.

2. Machine Learning
	- Enables systems to learn patterns from examples.
	- Uses algorithms that improve with more data.
	- Covers supervised, unsupervised, and reinforcement learning.
	- Common tasks: classification, regression, clustering.
	- Requires feature engineering or representation learning.
	- Quality depends on data cleanliness and labeling.
	- Models must be validated to avoid overfitting.
	- Deployment needs monitoring for drift and decay.
	- Ethical use requires fairness and explainability checks.
	- MLOps practices help maintain reliable pipelines.

3. Deep Learning
	- Uses multi-layer neural networks for complex patterns.
	- Excels in vision, speech, and natural language tasks.
	- Learns representations automatically from raw data.
	- Needs large datasets and high compute power.
	- Typical architectures include CNNs, RNNs, and transformers.
	- Training can be slow and sensitive to hyperparameters.
	- Overfitting is common without regularization techniques.
	- Model interpretability is challenging but important.
	- Transfer learning reduces data needs for new tasks.
	- Production use needs careful latency and cost control.

4. Data Science
	- Combines statistics, coding, and domain knowledge.
	- Turns raw data into insights and predictions.
	- Involves cleaning, exploration, modeling, and communication.
	- Uses tools like Python, R, and notebooks.
	- Requires understanding of business context and goals.
	- Emphasizes reproducible analysis and clear reporting.
	- Often creates dashboards and data stories.
	- Collaborates with engineering for data pipelines.
	- Balances accuracy with interpretability.
	- Measures success through impact on decisions and outcomes.

5. Data Analytics
	- Focuses on interpreting data for decision support.
	- Includes descriptive, diagnostic, and prescriptive analysis.
	- Uses SQL, BI tools, and visualization platforms.
	- Often works with structured, cleaned datasets.
	- Builds KPIs and reports for stakeholders.
	- Tracks trends, anomalies, and performance metrics.
	- Supports product, marketing, and operations teams.
	- Requires clear definitions of metrics and dimensions.
	- Data quality checks are essential for accuracy.
	- Communicates findings in concise, actionable terms.

6. Big Data
	- Handles large, fast, and varied datasets at scale.
	- Uses distributed storage and processing systems.
	- Common tools: Hadoop, Spark, and data lakes.
	- Enables batch and streaming analytics.
	- Requires careful schema management and governance.
	- Focuses on scalability, fault tolerance, and cost control.
	- Supports use cases like logs, IoT, and clickstreams.
	- Data ingestion pipelines must be reliable and fast.
	- Security and access control are critical at scale.
	- Optimization often targets storage and query performance.

7. Cloud Computing
	- Provides compute, storage, and services on demand.
	- Offers flexible scaling and pay-as-you-go pricing.
	- Models include IaaS, PaaS, and SaaS.
	- Leading platforms: AWS, Azure, Google Cloud.
	- Enables global deployment and disaster recovery.
	- Requires strong security and identity management.
	- Cost optimization needs monitoring and budgeting.
	- Supports serverless, containers, and managed databases.
	- Infrastructure can be automated via IaC tools.
	- Improves speed of delivery for modern applications.

8. Edge Computing
	- Processes data near devices instead of central clouds.
	- Reduces latency for real-time applications.
	- Useful for IoT, manufacturing, and smart cities.
	- Saves bandwidth by filtering data locally.
	- Requires lightweight models and efficient code.
	- Must handle offline and intermittent connectivity.
	- Security is critical due to distributed endpoints.
	- Works with gateways and edge servers.
	- Often pairs with cloud for centralized analytics.
	- Needs robust device management and updates.

9. Internet of Things
	- Connects sensors and devices to networks.
	- Captures real-world data for monitoring and automation.
	- Common in homes, factories, and healthcare.
	- Uses protocols like MQTT, CoAP, and HTTP.
	- Data volume can be large and continuous.
	- Requires secure device identity and access control.
	- Power constraints demand efficient hardware and software.
	- Firmware updates must be safe and reliable.
	- Analytics turns sensor data into actions.
	- Integration with cloud and edge is typical.

10. Cybersecurity Basics
	- Protects systems, networks, and data from attacks.
	- Covers confidentiality, integrity, and availability.
	- Involves policies, tools, and user training.
	- Common threats: phishing, malware, and ransomware.
	- Defense includes firewalls, antivirus, and monitoring.
	- Strong passwords and MFA reduce account risk.
	- Regular updates close known vulnerabilities.
	- Backups help recover from data loss events.
	- Incident response plans speed up recovery.
	- Risk assessment guides security priorities.

11. Network Security
	- Focuses on protecting network infrastructure and traffic.
	- Uses firewalls, IDS, and segmentation controls.
	- Monitors for unusual patterns and intrusions.
	- Applies least privilege to network access.
	- Encrypts data in transit where possible.
	- Implements VPNs for secure remote access.
	- Requires regular audits and configuration reviews.
	- DDoS protection maintains availability.
	- Logs and alerts support incident response.
	- Zero trust principles reduce lateral movement.

12. Application Security
	- Secures software against vulnerabilities and exploits.
	- Integrates security in design, code, and testing.
	- Uses SAST, DAST, and dependency scanning tools.
	- Common issues: injection, XSS, and auth flaws.
	- Secure coding standards reduce risk.
	- Threat modeling guides protective controls.
	- Regular patching fixes known weaknesses.
	- Code reviews catch security mistakes early.
	- Bug bounty programs invite external testing.
	- Security training helps developers avoid pitfalls.

	- Automates provisioning and deprovisioning.
	- Supports compliance with audit trails and logs.
	- Reduces risk from orphaned or stale accounts.
	- Integrates with cloud and on-prem services.
	- Privileged access requires extra safeguards.
	- Policy-based controls enforce consistent rules.
	- Improves user experience while maintaining security.

14. Cryptography
	- Protects data through encryption and hashing.
	- Ensures confidentiality, integrity, and authenticity.
	- Includes symmetric and asymmetric algorithms.
	- Key management is crucial for secure systems.
	- TLS secures data in transit across networks.
	- Hashes verify data without revealing contents.
	- Digital signatures prove authenticity and non-repudiation.
	- Weak keys or reuse can break security.
	- Compliance standards define approved algorithms.
	- Good crypto requires careful implementation practices.

15. Blockchain
	- Distributed ledger where records are tamper-evident.
	- Transactions are grouped into blocks and linked.
	- Consensus mechanisms keep nodes in agreement.
	- Supports use cases like payments and supply chains.
	- Public chains are open; private chains are controlled.
	- Smart contracts automate rules and workflows.
	- Scalability and energy use are key challenges.
	- Data on-chain is immutable once confirmed.
	- Security depends on network honesty and cryptography.
	- Governance models define updates and rules.
