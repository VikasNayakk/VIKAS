# Data Backup and Recovery

## Overview
Backups protect data from loss due to hardware failure, malware, or accidental deletion.

## Backup Types
- Full backup: Copies all data.
- Incremental: Copies changes since last backup.
- Differential: Copies changes since last full backup.

## Storage Options
- External drives.
- Cloud storage.
- Network attached storage (NAS).

## Best Practices
- Follow 3-2-1 rule: 3 copies, 2 media types, 1 offsite.
- Automate backups on a schedule.
- Test restore procedures.

## Recovery Steps
- Identify lost data scope.
- Restore from latest clean backup.
- Verify integrity after recovery.
