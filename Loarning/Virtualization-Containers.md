# Virtualization and Containers

## Overview
Virtualization runs multiple operating systems on a single machine. Containers package apps with their dependencies for consistent deployment.

## Virtual Machines (VMs)
- Hypervisors: VirtualBox, VMware, Hyper-V.
- Use cases: Testing, sandboxing, running legacy OS.

## Containers
- Tools: Docker, Podman.
- Concepts: Images, containers, registries.
- Benefits: Lightweight, fast startup, portability.

## Key Differences
- VMs: Full OS per instance, heavier.
- Containers: Share host OS kernel, lighter.

## Common Use Cases
- Development environments.
- Microservices deployment.
- CI/CD pipelines.
