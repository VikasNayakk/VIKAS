# Internet / Networking

## Overview
Networking connects devices to share data and access the internet. Knowing basic networking helps with Wi-Fi issues, speed problems, and security.

## Core Concepts
- IP Address: Unique address of a device (IPv4/IPv6).
- MAC Address: Hardware identifier for network devices.
- DNS: Converts domain names to IP addresses.
- DHCP: Automatically assigns IP addresses.

## Network Types
- LAN: Local Area Network (home/office).
- WAN: Wide Area Network (internet).
- WLAN: Wireless LAN (Wi-Fi).
- VPN: Secure private connection over the internet.

## Common Hardware
- Modem: Connects ISP to your network.
- Router: Shares internet to multiple devices.
- Switch: Connects devices within a LAN.
- Access Point: Extends Wi-Fi coverage.

## Wi-Fi Basics
- Bands: 2.4 GHz (longer range), 5 GHz (faster).
- Standards: 802.11n/ac/ax (Wi-Fi 4/5/6).
- Security: WPA2/WPA3 preferred.

## Speed Factors
- ISP plan limits.
- Router quality and placement.
- Device capability.
- Network congestion and interference.

## Basic Troubleshooting
- Restart modem and router.
- Check cables and ISP status.
- Forget and reconnect Wi-Fi.
- Use speed tests to compare expected vs actual.

## Security Practices
- Change default router password.
- Use WPA2/WPA3 encryption.
- Update router firmware.
- Disable WPS if not needed.

## Tools and Commands
- ping: Test connectivity.
- ipconfig: Show IP settings (Windows).
- tracert: Trace route to a server.
