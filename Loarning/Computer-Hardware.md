# Computer Hardware

## Overview
Computer hardware includes all physical components that make a computer system work. Good hardware knowledge helps in selecting parts, upgrading systems, and diagnosing issues.

## Core Components
### 1) CPU (Central Processing Unit)
- Role: Executes instructions and controls system operations.
- Key terms: Cores, threads, clock speed (GHz), cache (L1/L2/L3), architecture.
- Common issues: Overheating, thermal throttling, bent pins, unstable performance under load.

### 2) Motherboard
- Role: Main circuit board connecting all components.
- Key terms: Chipset, socket type, RAM slots, PCIe lanes, VRM, BIOS/UEFI.
- Common issues: Incompatible CPU/RAM, failing capacitors, BIOS corruption.

### 3) RAM (Memory)
- Role: Temporary working storage for active data.
- Key terms: DDR generations, frequency (MHz), latency (CL), dual-channel.
- Common issues: Random crashes, memory errors, failure to boot.

### 4) Storage
- Types: HDD, SATA SSD, NVMe SSD.
- Key terms: Read/write speed, IOPS, endurance (TBW), SMART.
- Common issues: Slow boot, bad sectors, data corruption.

### 5) GPU (Graphics Processing Unit)
- Role: Renders graphics and parallel workloads.
- Key terms: VRAM, CUDA cores/stream processors, driver versions.
- Common issues: Artifacts, driver crashes, thermal issues.

### 6) Power Supply (PSU)
- Role: Converts AC to DC power for components.
- Key terms: Wattage, efficiency (80 Plus), rails, protections.
- Common issues: Random shutdowns, coil whine, unstable voltage.

### 7) Cooling System
- Types: Air cooling, liquid cooling.
- Key terms: TDP, airflow, fan curve, thermal paste.
- Common issues: Dust buildup, pump failure, noisy fans.

### 8) Peripherals
- Devices: Keyboard, mouse, monitor, printer, speakers, webcam.
- Common issues: Driver conflicts, cable failures, port issues.

## Interfaces and Buses
- SATA: Storage interface (HDD/SSD).
- PCIe: High-speed expansion (GPU, NVMe).
- USB: Universal peripheral interface.
- HDMI/DisplayPort: Video output standards.

## Compatibility Basics
- CPU socket must match motherboard.
- RAM type must match motherboard (DDR4/DDR5).
- PSU wattage must meet system load.
- Case size must match motherboard form factor (ATX, mATX, ITX).

## Maintenance Tips
- Clean dust regularly to avoid heat issues.
- Keep BIOS and drivers updated.
- Monitor temps with tools like HWMonitor or HWiNFO.
- Use a surge protector or UPS for power safety.

## Quick Diagnostics
- No power: Check PSU switch, power cable, motherboard LED.
- No display: Reseat RAM/GPU, test with onboard graphics.
- Random reboot: Check temps, PSU health, RAM errors.
