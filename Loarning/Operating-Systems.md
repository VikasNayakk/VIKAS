# Operating Systems

## Overview
An operating system (OS) manages hardware resources and provides services for applications. Understanding OS basics helps with performance, security, and troubleshooting.

## Core Functions
- Process management: Runs programs, schedules CPU time.
- Memory management: Allocates RAM, handles virtual memory.
- File system: Organizes data on storage.
- Device management: Uses drivers to control hardware.

## Popular OS Families
- Windows: Desktop and enterprise use.
- Linux: Servers, development, cloud.
- macOS: Apple hardware ecosystem.

## Key Concepts
- Kernel: Core of the OS.
- User vs kernel mode.
- File permissions.
- Services/background processes.
- Updates and patches.

## Basic Admin Tasks
- Create users and set permissions.
- Install and update software.
- Manage startup services.
- Monitor resources (CPU/RAM/Disk).

## Troubleshooting Basics
- Safe mode boot.
- Check logs and error codes.
- Restore points and recovery tools.
