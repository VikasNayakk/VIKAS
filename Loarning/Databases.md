# Databases

## Overview
Databases store and organize data so it can be quickly accessed and updated.

## Types
- Relational (SQL): MySQL, PostgreSQL, SQL Server.
- NoSQL: MongoDB, Redis, Firebase.

## Core Concepts
- Tables, rows, columns.
- Primary and foreign keys.
- Indexes for faster queries.
- CRUD: Create, Read, Update, Delete.

## SQL Basics
- SELECT, INSERT, UPDATE, DELETE.
- WHERE, ORDER BY, GROUP BY.
- JOIN to combine tables.

## Use Cases
- Websites and apps.
- Analytics and reporting.
- Logging and audit trails.

## Best Practices
- Normalize data when appropriate.
- Back up regularly.
- Use access control and roles.
